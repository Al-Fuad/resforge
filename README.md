# ResForge

Official Next.js website for ResForge, an independent research collective working on reliable AI, cognitive systems, and efficient on-device intelligence.

## Local preview

Install dependencies and start the Next.js development server:

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.

## Structure

- `app/` — App Router pages, metadata, and global visual system
- `components/ResearchSite.tsx` — interactive research landing page

## Deployment

Run `npm run build` to create a production build. The site is ready for Vercel or any Next.js-compatible host.

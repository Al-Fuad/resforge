# ResForge

Official website for ResForge, an independent research collective working on reliable AI, cognitive systems, and efficient on-device intelligence.

## Local preview

This is a dependency-free static site. Serve the repository root with any local web server, for example:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Structure

- `index.html` — page content and semantics
- `styles.css` — responsive visual system and motion
- `script.js` — navigation, reveal effects, and research-pipeline interaction

## Deployment

The site can be deployed directly to GitHub Pages, Vercel, Netlify, or any static host.
